# Docker Pause Manager

自动休眠和唤醒 Docker 容器的 Web 管理工具。

## 功能

- **自动休眠**：监控容器在设定时间内无活动时自动 pause
- **自动唤醒**：休眠期间检测到新连接时毫秒级 unpause
- **Web UI**：中英双语切换、日间/夜间高对比度模式
- **容器自动发现**：添加容器时自动列出所有 Docker 容器及端口
- **灵活配置**：每个容器可单独设置空闲超时，或使用全局设置
- **安全登录**：管理员密码登录，会话有效期 1 小时

## 部署

```bash
docker compose up -d
```

访问 `http://<host>:5287`，默认密码 `admin123`。
